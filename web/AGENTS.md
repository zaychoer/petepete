# Web (TanStack Start)

This is a TanStack Start v1 RC app with React 19, Vite, and Tailwind CSS v4.

## Framework

- **TanStack Start** (`@tanstack/react-start`) with `@tanstack/react-router` for file-based routing.
- **Vite** as the build tool; `vite.config.ts` configures `tanstackStart()`, `nitro()`, `react()`, and `@tailwindcss/vite`.
- **Nitro** for Node.js server deployment (build output in `.output/`).

## File structure

- `src/routes/` — file-based routes: `__root.tsx` (root layout), `index.tsx`, `pay.$token.tsx`, `join.$token.tsx`, `kebijakan-privasi.tsx`, `syarat-ketentuan.tsx`.
- `src/components/` — shared UI components (`legal.tsx`, `join-form.tsx`, `pay/` directory).
- `src/lib/` — pure logic and API client (no framework imports). Tests live next to their modules.
- `src/styles/globals.css` — Tailwind CSS v4 entry point.
- `src/router.tsx` — TanStack Router configuration.
- `src/client.tsx` — client entry (Sentry init + hydration).
- `src/server.ts` — server entry (Sentry init + server handler).
- `src/routeTree.gen.ts` — auto-generated by the router plugin; do not edit.

## Routes

Routes use `createFileRoute` with `loader` for server-side data fetching via `createServerFn`. The pay and join pages fetch API data server-side and pass it to client components.

## Sentry

`@sentry/tanstackstart-react` replaces `@sentry/nextjs`. Initialised in `src/client.tsx` (browser) and `src/server.ts` (server). Phone masking via `src/lib/sentry-scrub.ts` is unchanged.

## Environment variables

Vite exposes `VITE_*` variables to client code. Key variables:
- `VITE_API_BASE_URL` — API origin (replaces `NEXT_PUBLIC_API_BASE_URL`).
- `VITE_SENTRY_DSN` — Sentry DSN (replaces `NEXT_PUBLIC_SENTRY_DSN`).

## Scripts

- `pnpm dev` — `vite dev`
- `pnpm build` — `vite build` (outputs to `.output/`)
- `pnpm start` — `node .output/server/index.mjs`
- `pnpm test` — `vitest run`
- `pnpm lint` — `eslint`
